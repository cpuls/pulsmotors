# Puls Motors Website

Static v1.0 website for Puls Motors, built around the supplied Puls Motors logo and intended for GitHub Pages at `pulsmotors.com`.

## Preview Locally

Open `index.html` directly in a browser, or run a tiny local server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
